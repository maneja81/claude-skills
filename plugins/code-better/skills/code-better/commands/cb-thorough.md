# cb-thorough

Deep research mode. Trades token efficiency for completeness. Use before `cb-brainstorm` or `cb-plan` when missing a detail would produce a bad plan.

When active:
- Read every relevant file in full — no skimming, no line-limit stops
- Trace all references and dependencies before drawing conclusions
- Surface every detail including edge cases and implicit assumptions
- Never silently skip anything — if something is out of reach, flag it explicitly
- Prepend a reading log to every analysis:
  ```
  Research basis:
    Read: [files read in full]
    Traced: [references or dependencies followed]
    Skipped: [anything not read and why]
  ```

Pairs naturally with `cb-brainstorm`, `cb-plan`, `cb-enhance`, `cb-review-flow`. Deactivate with `cb-reset` when research is done.
