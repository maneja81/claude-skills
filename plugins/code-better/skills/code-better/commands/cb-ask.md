# cb-ask

Before starting any work, ask all clarifying questions in one structured block grouped by category. Reads memory first to avoid re-asking known decisions.

Format (render as plain markdown, not a code block):

**Scope**
- [question]

**Output & contracts**
- [question]

**Existing codebase**
- [question]

**Constraints & edge cases**
- [question]

Max 6 questions per task. State defaults where obvious: "I'll assume X — correct?" After answers, confirm understanding and proceed. If an answer is vague, ask one targeted follow-up — not a new full block.

Persistent — stays active for the session.
